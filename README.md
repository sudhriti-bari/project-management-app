#  Project Management App

A full-stack **Project Management System** built using the MERN stack (MongoDB, Express, React, Node.js).  
This application helps users manage tasks efficiently with authentication, dashboards, and task tracking features.

---

##  Features

- User Authentication (Signup / Login with JWT)
- Create, Read, Update, Delete (CRUD) Tasks
- Admin Dashboard with task overview
- Role-based access (User/Admin)
- RESTful API integration
- Task status tracking (Pending / In Progress / Completed)
- MongoDB database integration
- Secure password hashing using bcrypt

---

##  Tech Stack

### Frontend
- React.js
- Axios
- React Router DOM
- CSS (Custom Styling)

### Backend
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT Authentication
- bcrypt.js
